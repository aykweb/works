## 制作のポイント

Fetch APIによりヘッダー・フッターを共通化し、保守性を向上。

- **アクセシビリティの調整**  
ARIA属性によるモーダルやフォーカス設定、200%拡大時のレイアウト崩れ防止など、WCAGを意識した実装に取り組み中。

- **問い合わせフォームの実装**  
SSGformを導入し、データの送受信を実装。

- **保守性の高いCSS設計**  
カラー、余白、フォントにCSS変数を活用し、一括管理を実現。
