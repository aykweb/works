## 制作のポイント
- **CSS設計手法(BEM × FLOCSS)によるSass設計**  
BEMでクラス名を統一し、FLOCSSに基づいてfoundation/layout/objectレイヤーに分割。`@use`/`@forward`によるモジュール管理と、`@mixin`によるスタイルの再利用を行い、保守や拡張がしやすい設計にしています。

- **アクセシビリティの調整**  
モーダルウィンドウの開閉には`inert`属性を用いたフォーカストラップを実装し、キーボード操作に対応しています。ARIA属性の適切な付与、200%拡大時のレイアウト崩れ防止など、WCAGを意識した実装に取り組んでいます。

- **モーダルウインドウでの作品紹介**  
データが増えた際の管理のしやすさを考慮し、カスタムデータ属性を使用。

- **JavaScriptによるパーツ共通化**  
Fetch APIによりヘッダー・フッターを共通化し、保守性を向上。

- **問い合わせフォームの実装**  
SSGformを導入し、データの送受信を実装。

- **CSSカスタムプロパティの活用**  
カラー、余白、フォントにCSS変数を活用し、一括管理を実現。Sass変数ではなく実行時に値を扱えるCSS変数で管理することで、柔軟性を保っています。
